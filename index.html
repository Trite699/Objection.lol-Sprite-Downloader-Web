Objection.lol Character Sprite Downloader

Save the sprites from an objection.lol character as a ZIP. Runs entirely in your browser; nothing is uploaded.

Paste character data
  1. On objection.lol, load the character (My Assets → Characters, or open a case that uses it).
  2. Open DevTools (F12 or Ctrl/Cmd+Shift+I) → Network → filter Fetch/XHR.
  3. Reload, click the request that returns the character's JSON, open Response, and copy it all.
  4. Paste it below.
